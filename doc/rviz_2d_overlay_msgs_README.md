# rviz_2d_overlay_msgs

## 概要

`rviz_2d_overlay_msgs` は、RViz の 3D 画面上に 2D 情報を重ね描きするためのメッセージ定義パッケージです。  
自体では表示機能を持たず、`rviz_2d_overlay_plugins` の入力メッセージを定義します。

## 主なメッセージ

### `OverlayText.msg`

テキストオーバーレイのためのメッセージです。

主なフィールド:

- 表示サイズ
- 画面内の位置
- 左寄せ、中央、右寄せなどの配置指定
- 前景色、背景色
- フォント
- 実際のテキスト

## このワークスペースの中での位置づけ

現状の主要 launch では直接使われていませんが、RViz 上にステータス文字列を重ねたいときの基盤になります。  
将来的にバッテリ状態、認識結果、ミッション状態などを RViz に直接載せたい場合に使いやすいパッケージです。

## どこで使われているか

- `rviz_2d_overlay_plugins`

## 初見の人が最初に確認するとよいファイル

- `msg/OverlayText.msg`

## 補足

- 画面上の配置や色指定までメッセージ側に持たせているため、表示ノード側でレイアウトを細かく調整しやすい設計です。
